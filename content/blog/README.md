# Blog posts — drop files here

Anything you drop in this folder becomes a blog post on **blog.html**, newest
at the top. Then commit / push (or use GitHub's **Add file → Upload files**) —
the site rebuilds and deploys automatically.

Supported files:
- **.md / .markdown** — Markdown (headings, links, images, lists, bold…)
- **.txt** — plain text
- **.docx** — Word documents (converted to formatted HTML)
- **.pdf** — embedded inline with a download link

Ordering & titles:
- Start the filename with a date to control order and show it, e.g.
  `2026-09-29-my-update.md`. No date prefix → the file's last commit date is used.
- The post title is the first `# Heading` in a .md/.txt file, otherwise the
  filename (prettified).

This README is ignored — it never becomes a post.
